# Na Maré — página de vendas
Página estática. O aplicativo NÃO fica neste repositório (é entregue pela Kiwify).
- `index.html`: página de vendas (troque `window.KIWIFY` pelo link do checkout).
- `versao.json`: avisa os apps instalados que há versão nova.

## O que o Na Maré NÃO faz
Não sincroniza a agenda do Airbnb sozinho (precisa de servidor), não une celular e computador, não cobra nem libera por assinatura nem controla cópias, não se conecta sozinho ao Airbnb (importação manual; importador ainda não validado com arquivo real), Raio X por link depende de leitor público de terceiros (pode falhar, não lê calendário); backup automático só no Chrome/Edge do computador; imposto é estimativa e não substitui contador.
